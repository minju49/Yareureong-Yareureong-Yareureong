봄카페 · 실제 음성 연결 점검

말한 문장이 어디에서 달라질까?

마이크 → SenseVoice → 문장 재점검 → 학교 Qwen → 필드 검증

녹음을 마친 뒤 최종 문장을 인식합니다. 이 화면은 실험용이며 장바구니·TTS·결제는 실행하지 않습니다.

1. 모델 확인

모델 상태를 읽고 있어요.

Qwen은 확인 버튼을 누르기 전에는 호출하지 않습니다.

SenseVoice 점검은 동봉한 합성 음성을 실제로 인식합니다. 마이크 녹음은 다음 단계에서 확인하세요.

2. 말할 내용과 직전 질문

직전 질문 없음 · 새 문장으로 입력합니다.

자유롭게 주문 문장을 말해보세요.

정답표와 비교하지 않고 실행 결과를 저장합니다.

짧은 답변 시험은 위에 적힌 질문을 받은 상황을 가정합니다. 선택한 문맥을 두 Qwen 경로에 똑같이 전달합니다. 자동 대화가 이어지는 기능은 아닙니다.

3. 마이크로 녹음하기

녹음은 0.2~30초입니다. 종료 후 먼저 재생해보세요.

실제 장치 이름은 마이크 확인 후 표시됩니다.

원본 WAV 저장

아직 준비한 음성이 없습니다.

녹음 설정 보기
브라우저의 잡음 억제·반향 제거·자동 음량 조절을 요청합니다. 실제 적용값은 녹음별로 저장합니다.

4. 같은 음성으로 비교하기

선택을 끄면 실제 STT·문장 재점검까지만 실행합니다. 선택하면 인식 원문 A와 재점검문 B를 비교합니다. 문장이 같으면 한 번만 호출합니다.

정답 전사와 주문 필드 대조 · 선택 사항

녹음을 직접 듣고 실제로 말한 글을 적으세요. 화면의 예문을 들은 것으로 간주해 자동 입력하지 않습니다.

이 확인 전에는 주문 정답률을 채점하지 않습니다. 마지막 4개는 정해진 JSON 하나로 채점하지 않습니다.

음성을 먼저 준비해주세요.
