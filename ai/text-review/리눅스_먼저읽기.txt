봄카페 · 리눅스 문장 재점검 실험
현재 보정 0.5 / 리눅스 실행 1.0

처음부터 다시 실험을 만들 필요는 없습니다.
기존 코드·문장·판정 기준·학교 Qwen 설정을 그대로 사용합니다.
이 파일은 문장 재점검 실험용이며 마이크·STT·TTS·키오스크·DB 전체 실행본은 아닙니다.

먼저 할 일
1. ZIP을 홈 폴더 등 쓰기 가능한 곳에 모두 압축 해제합니다.
2. 압축 해제한 bom-text-review-linux 폴더에서 터미널을 엽니다.
3. 다음 한 줄을 입력합니다.

   bash 0_시작하기.sh

4. 번호를 고르는 메뉴가 나와야 합니다.
5. 처음에는 1번으로 파일·Python을 확인합니다. 이 단계는 학교 서버에 연결하지 않습니다.
6. 준비 확인 완료가 나오면 2번으로 학교 Qwen 연결을 확인합니다.
7. 실제 모델 이름·JSON 응답·실행 기록 위치가 나와야 합니다.
8. 연결 확인 후 3번으로 개발56문장, 4번으로 과거 STT43문장을 비교합니다.
9. 시간이 되면 5번으로 기능별24문장을 3회 비교합니다.
10. 끝나면 새로 생긴 records 폴더 전체를 복사해 보관합니다.

파일별로 바로 실행할 수도 있습니다.
bash 1_학교연결점검.sh
bash 2_학교56문장비교.sh
bash 3_실제STT기록43문장비교.sh
bash 4_학교기능별반복비교.sh

필요한 것
- Linux에서 실행되는 Python 3.10 이상입니다. 이 ZIP에 Windows Python을 넣지 않았습니다.
- 추가 pip 패키지는 필요하지 않습니다.
- Qwen 모델을 새로 받거나 이 PC에 Ollama를 설치하는 단계가 아닙니다.
- 학교 서버에 접근할 수 있는 네트워크가 필요합니다.
- 개인 전달용 ZIP에는 school.local.json의 주소와 43개 입력 자료를 넣었습니다.
- 예전 audio-suite 폴더를 찾을 필요가 없습니다.

안 될 때
- Permission denied: 파일 더블클릭 대신 위의 bash 명령으로 실행합니다.
- No such file: 터미널의 현재 폴더에 0_시작하기.sh가 있는지 ls로 확인합니다.
- Python 버전 오류: python3 --version 결과를 알려주세요. 시스템 Python을 삭제하거나 바꾸지 않습니다.
- 연결 거부/시간 초과: 학교 네트워크와 Qwen 서버 상태를 확인합니다.
- 모델 없음: qwen3.5:9b-q4_K_M 이름과 실제 목록을 확인합니다.
- 결과 화면이 안 열림: records의 해당 결과 폴더에서 결과요약.html을 직접 엽니다.
- 기타 오류: records/linux-launch의 마지막 log 파일을 보관합니다.

Windows용 .cmd나 python.exe는 리눅스에서 실행하지 않습니다.
학교 Qwen이 실제 동작하는지는 학교 연결 점검을 통과해야 확인됩니다.
집실험기록·추가_집실험기록은 집 0.8B의 과거 결과이며 새 학교 결과가 아닙니다.
정답표_검토용.html에서 팀원의 검수 의견을 저장합니다. 저장만으로 정답 파일이 자동 수정되지는 않습니다.
검수 전 점수는 개발용 정답 초안 기준이며 실제 주문 완료율이 아닙니다.
