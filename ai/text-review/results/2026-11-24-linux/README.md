# 리눅스 실행 지원

기존 보정 0.5·주문 검증·Qwen 요청 설정을 유지하고 Linux 실행 파일과 메뉴를 추가했다. 시스템 Python 3.10 이상과 표준 라이브러리만 사용한다. Windows의 python.exe와 .cmd를 실행하지 않는다.

Linux Python 3.10.22와 3.14.10에서 각각 126개 검사가 통과했다. 일반 사용자 UID1000, 한글·공백 경로, 오프라인 준비 확인, 메뉴, 오류 로그를 점검했다. 네이티브 /api/tags·/api/chat 계약과 56/43/기능별 실행 경로는 네트워크를 차단한 컨테이너 내부의 로컬 HTTP 시험 응답으로 확인했다. 실제 학교 모델 연결이나 정확도 평가가 아니다. 시험용 응답·점수는 제품/배포 records에 넣지 않았다.

`bash 0_시작하기.sh`로 시작한다. 리눅스 개인 전달용 ZIP에는 학교 주소와 기존43개 입력 자료를 함께 넣는다. Git 소스에는 사설 설정과 과거 실제 STT 원본 기록을 올리지 않는다. 실제 학교 Qwen 연결은 학교에서 별도 확인해야 한다.
