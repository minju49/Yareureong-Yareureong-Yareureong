## 공개 범위와 재현

원본 요청·모델 응답·이전 실제 음성 로그·개인 PC 경로는 로컬에 보관한다. 공개한 CSV는 개발용 문장별 점수·판정·시간이다.

`protocol.json`의 해시는 실험 당시 원본 코드의 해시다. Git 공개본은 학교 주소를 환경 변수로 변경하고 Python 선택 실행 파일을 추가했다. 집 모델에 전달하는 프롬프트·메뉴·정답표·추론 설정은 바꾸지 않았다. 공개본의 처리 코드를 실험 당시 원본과 비트 단위로 동일하다고 주장하지 않는다.

과거 CSV 221행은 중복 제거 후 60요청이며 마이크 입력은 49요청, 서로 다른 마이크 문장은 45개였다. 재점검으로 바뀐 16요청을 개선으로 세지 않았다. WAV·검수 정답이 없어 CER는 계산하지 않았다.

남은 일은 정답표의 독립 검수와 새 음성·학교 모델의 별도 확인이다. 이 개발 점검만으로 일반적 개선, 발화별 무악화 또는 실제 주문 성공을 보장하지 않는다.
