STT → 문장 재점검 → Qwen · 구현 기준 0.5

1. 입력과 출력
입력은 STT 최종 문장과, 선택적으로 이미 확인된 직전 질문 문맥이다.
원문, 정리한 문장, 고친 이유, 메뉴 후보, 문맥 사용 여부, 처리 시간을 반환한다.
이 모듈은 장바구니를 저장하거나 가격·결제를 확정하지 않는다.

2. 문장을 어떻게 재점검하나
① 유니코드 NFC로 문자 저장 방식을 정리한다. 원문은 따로 보관한다.
② 등록된 온도·휘핑·정정 단어 내부의 공백만 붙인다. 문자·수량·옵션 값은 추가하지 않는다.
   예: 따 뜻한 → 따뜻한, 휘 핑 → 휘핑. 아 한 잔을 아아 한 잔으로 추정하지 않는다.
   전처리 이력의 위치는 unicode_normalized_original, 메뉴 이력은 option_spacing_normalized_text 기준이다.
③ 승인 줄임말과 표기를 정식 메뉴로 바꾼다. 아아/뜨아/따아/아바라만 사용한다.
④ 의심되는 메뉴는 한글 자모 편집 거리로 후보를 비교한다.
   similarity = 1 - 편집 거리 / 두 문자열 중 더 긴 자모 수
⑤ 최소 4음절, 자모 편집 1회 이내, 유사도 0.88 이상, 다음 후보와 차이 0.15 이상을 초기 개발 기준으로 사용한다.
   이 값은 최적 임계값이나 STT 확률이 아니다. 수량·온도·부정·정정 표현은 추정하지 않는다.
⑥ 오타 후보로 바꾼 메뉴도 확인 없이 확정하지 않는다. 애매하면 후보만 제시한다.
⑦ 직전 질문이 명시되고 짧은 답변이 맞을 때만 알려진 메뉴·수량·온도와 연결한다.
   자동 대화 상태 관리와 장바구니 연동은 별도 구현 대상이다.

3. Qwen 요청 원칙
같은 메뉴·프롬프트·이전 문맥·생성 설정에서 A 원문과 B 재점검문을 비교한다.
정답표는 요청에 넣지 않는다. 보정문과 원문이 같으면 실제 응답 하나를 공유한다.
실제 요청 내용과 Qwen 원본 JSON을 저장한다.
집 0.8B와 학교 9B는 별도 결과다. 서로의 점수 차이를 보정 효과로 계산하지 않는다.

4. 별도 검증
등록 메뉴, 명시 수량, 온도, 필수 휘핑과 응답의 의도·질문 상태를 확인한다.
수량이 없으면 1잔으로 채우지 않는다. 단위가 이상하면 숫자 후보와 단위 확인을 구분한다.
Only Ice는 매장 고정값을 적용할 수 있으나 모델 원본 null을 고친 답변처럼 보관하지 않는다.
미등록 메뉴, 불명확한 대상, 복합 정정, 특이 제조 요청은 확인 없는 단일 추가 수락을 막는다.
재점검에서 확인하지 못한 표현은 다음 검증 단계로도 전달한다. 알려진 메뉴만 남겨 요청 일부를 수락하지 않는다.
현재 단일 메뉴 검증기는 메뉴 뒤에 추가 요청을 잇는 표현이 있으면 보수적으로 확인한다. 복합 주문의 정상 자동 처리기는 별도 구현 대상이다.
차단된 요청을 성공 주문으로 세지 않는다. 확인 가능한 완성 입력이 실제로 통과한 수도 함께 본다.

5. 지표 정의
핵심 슬롯 개별 일치 = 맞은 핵심 슬롯 수 / 채점 가능한 핵심 슬롯 수.
핵심 슬롯은 메뉴·수량·온도와 해당 메뉴에 필수인 휘핑이다. 고정 사이즈와 빈 메모는 빼서 지표를 부풀리지 않는다.
수량·온도 미지정 null도 정답 상태다. 근거 없는 추정을 잡기 위해 채점한다.
핵심 슬롯 모두 일치 = 해당 문장의 핵심 슬롯이 모두 맞은 문장 수 / 단일 메뉴 채점 문장 수.
응답 전체 조건 일치 = 위 항목과 사이즈·메모·의도·질문 유무까지 모두 맞은 문장 수 / 해당 채점 문장 수.
질문 내용의 실제 적절성은 이 자동 지표에 포함하지 않는다.
API·JSON 실패는 별도로 기록하고 전체 분모에서 빼지 않는다. 정상 JSON 공통 부분집합도 따로 표시한다.
개선/악화 = 같은 입력의 A/B 조건 일치가 서로 바뀐 사례. 형식 실패 해소는 의미 개선과 구분한다.

6. 자료와 해석 범위
직접 만든 개발 문장 56개와 과거 마이크 기록의 관측 문장 분석을 분리한다.
과거 CSV 221행을 내보내기 중복 제거하면 60요청, 마이크 입력은 49요청이다.
마이크 입력은 서로 다른 원문 45개, 공백·문장부호를 묶으면 43개다.
43개 중 보이는 문장만으로 단일 메뉴 필드를 명확하게 정할 수 있는 18개에 정답 초안을 작성했다.
직전 질문이 없거나 메뉴가 불명확하거나 복합 동작인 25개는 전체 주문 정답을 추측해 채점하지 않는다.
이전 기록에는 원본 WAV와 검수 전사가 없어 음성 CER를 계산하지 않는다.
정답 초안은 독립 검수 전이다. 신규 발화·고령자·다양한 소음의 최종 시험셋으로 해석하지 않는다.

7. 정확한 명칭
메뉴 사전 기반 텍스트 후처리와 후보 순위 비교다.
STT가 낸 여러 음성 인식 후보(N-best)나 음향 확률을 다시 평가한 방식은 아니다.
모델 가중치를 재학습한 것도 아니다.
