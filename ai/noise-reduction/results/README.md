# 실험 결과

모든 문자 오류율(CER)은 같은 발화를 같은 SenseVoiceSmall로 인식한 짝 비교 기준이다. ZipEnhancer 0.25는 신호 영역에서 원본 75%와 모델 출력 25%를 혼합한 조건이다.

| 자료 | 발화 | OFF CER | ON CER | CER 차이의 95% 구간 |
|---|---:|---:|---:|---:|
| 새 원본 44개의 자연 대화 | 633 | 13.06% | 11.92% | -1.89 ~ -0.46%p |
| 세 가지 카페 소음 | 90 | 24.39% | 22.99% | -2.67 ~ -0.28%p |

90개는 대화소음·업소소음·기타 카페 소음 각 30개이며, 적용 후 25개 개선·50개 동일·15개 악화였다. 잡음 제거는 발화당 평균 0.63초였다. 유형별 차이의 범위는 0에 닿거나 포함됐다. 구간은 원본 단위의 짝 bootstrap으로 추정했다. 두 표본은 같은 AI Hub Training 자료에서 나온 별도 비교이며 합산하지 않았다.

확대 조합 비교에서 입력별 모델 선택은 633발화 CER 11.90%, ZipEnhancer 단독은 11.92%였다. 두 조건의 차이 범위에는 0이 들어왔다. 20개 시간 점검에서는 선택 방식 약 1.28초와 ZipEnhancer 단독 약 0.60초가 측정돼, 단독 모델을 시연 후보로 남겼다.

기존 별도 Python 키오스크에서 파일 업로드와 음성 스트림의 OFF/ON을 확인했다. 90개를 다시 인식해 기존 평가의 두 조건 180건과 같은 인식 문장을 얻었다. 합성 주문에서 메뉴·수량·온도 표현이 모두 남은 사례는 조용한 조건 3/3 → 2/3, 배경 대화를 섞은 조건 1/3 → 2/3이었다. 이 자료의 표본은 3문장이므로 실제 주문 성공률이나 자동 적용 조건을 확정하기에는 부족하다.

출처는 [AI Hub 소음 환경 음성인식 데이터](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&dataSetSn=568)다. 이 저장소에는 집계만 포함한다.

## 입력별 자동 선택

개발 원본 100개에서 최대 깊이 2, 잎당 최소 20건인 결정트리로 후보별 `CER + 0.001 × 처리 초`의 손실이 낮은 경로를 고르도록 했다. 네 가지 음향 특징 중 정책에는 프레임 에너지 백분위수 비율만 남았다. 개발과 원본이 겹치지 않는 42개 출처의 150발화에서 정책을 고정한 뒤 기존 경로별 STT 결과를 다시 집계했다. 표의 시간은 기존 잡음 제거 측정값이며 새 측정이나 전체 주문 응답 시간이 아니다.

| 처리 | CER | 발화당 평균 잡음 제거 시간 |
|---|---:|---:|
| OFF | 15.06% | 생략 |
| ZipEnhancer | 14.07% | 0.35초 |
| MossFormerGAN | 14.27% | 0.82초 |
| 병렬 조합 | 13.99% | 1.17초 |
| MossFormerGAN → ZipEnhancer | 14.07% | 1.17초 |
| ZipEnhancer → MossFormerGAN | 13.72% | 1.19초 |
| AUTO | 14.03% | 0.73초 |

AUTO는 단독 78회, MossFormerGAN → ZipEnhancer 41회, 반대 순서 31회를 선택했다. ZipEnhancer 단독 대비 AUTO의 CER 차이 95% 구간은 −0.55~+0.49%p, ZipEnhancer → MossFormerGAN의 구간은 −0.92~+0.24%p로 두 구간 모두 0을 포함했다. 화면에는 AUTO와 조합을 실험 모드로 제공한다. 전체 집계는 [auto-summary.json](auto-summary.json)에 있다.
